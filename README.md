# JS-tasker на React
## Суть задачи
Создать прототип CRUD WEB-приложения с задачами с использованием чистого JS, HTML, CSS

## Инструкция по запуску
*Для Windows:*
1. Запустите командную строку в папке WEB52-Tasker/tasker
Или просто перейдите в текущую папку, нажмите на путь текущей папки. Вместо нее напишите `cmd`
2. Установите необходимые модули с помощью `npm install`. Важно: у вас уже должен быть установлен NodeJS и npm. Если нет, то скачивайте [Здесь](https://docs.google.com/spreadsheets/d/1Vp87DAyLYZ3li4JeiPlQ6XxGQePlsu5BULFUtUS116A/edit?usp=sharing)
3. Пропишите в консоли `npm run dev`
4. Спустя время он покажет вот такое окно.
<img width="291" height="84" alt="image" src="https://github.com/user-attachments/assets/7ecde40a-a417-4424-971b-9b46f9e00320" />

Это значит, что проект запустился и уже "публикует" страницу по адресу, который представлен в консоли. По умолчанию это `localhoost:5137`

Консоль не нужно перезапускать при внесении изменений или появлении ошибок. Любая правка кода мгновенно влияет на хост.
